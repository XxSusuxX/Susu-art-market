# 🎨 Susu - Art Market (Hobby Showcase)

[![Live Demo](https://img.shields.io/badge/Demo-Vercel-blue.svg?style=for-the-badge&logo=vercel)](https://susu-art-market.vercel.app/)

## ⚠️ CONTEXTO DO PROJETO ⚠️
Este é um repositório histórico de um projeto antigo que foi criado exclusivamente para exibir meus desenhos e ilustrações (um hobby secundário). **Ele NÃO é uma loja funcional.** Nenhum produto pode ser comprado realmente, e o sistema de "carrinho de compras" é apenas uma simulação visual.

---

## 📄 Descrição do Projeto

O **Susu - Art Market** é um site estático simples construído para apresentar uma coleção pessoal de arte digital e analógica (escaneada/desenhada à mão). O layout foi projetado para simular a experiência de navegação de um e-commerce de arte independente, focando apenas na estrutura e no estilo.

### 🖼️ Estrutura do Site

Conforme o design do projeto, o site está organizado em duas seções principais:

1.  **Cabeçalho e Seção "Sobre a loja":** Apresenta o nome do projeto "Susu - Art attack" (no logo) e um texto introdutório que convida o visitante a explorar a diversidade de estilos das criações exclusivas.
2.  **Seção "Produtos":** Uma grade visual que exibe miniaturas dos desenhos com títulos, descrições breves e botões de simulação ("Adicionar ao carrinho").

## 🎨 Coleção de Arte (Hobby)

O site apresenta diversos estilos de arte, incluindo:
*   **Desenhos Tradicionais à Lápis/Nanquim:** Ex: "Amor Natural", "Grito Interior".
*   **Fan Art de Anime/Mangá:** Ex: "Ichigo, de Bleach", "Kaneki" (de Tokyo Ghoul).
*   **Ilustrações Estilizadas:** Ex: "Explosão de fofura", "O Gato" (inspirado no País das Maravilhas).

## 🛠️ Stack Tecnológica

Este projeto foi construído utilizando os fundamentos da web, sem frameworks adicionais, garantindo leveza e carregamento rápido:
*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização, layout em grid/flexbox e responsividade.
*   **Hospedagem:** Vercel.

## 🚀 Como Visualizar

### 1. Visualizar a Demonstração ao Vivo
A maneira mais fácil de interagir com o design é acessar o link de demonstração hospedado na Vercel:

👉 **[susu-art-market.vercel.app](https://susu-art-market.vercel.app/)**

### 2. Executar Localmente
Como este é um projeto estático (apenas HTML e CSS), rodar localmente é extremamente simples:
1. Clone este repositório: `git clone https://github.com/XxSusuxX/Susu-art-market.git`
2. Navegue até a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador padrão.
