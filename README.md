# 🎨 Susu - Art Market (Hobby Showcase)

[![Live Demo](https://img.shields.io/badge/Demo-Vercel-blue.svg?style=for-the-badge&logo=vercel)](https://susu-art-market.vercel.app/)

## ⚠️ CONTEXTO DO PROJETO ⚠️
Este é um repositório histórico de um projeto antigo que foi criado exclusivamente para exibir meus desenhos e ilustrações (um hobby secundário). **Ele NÃO é uma loja funcional.** Nenhum produto pode ser comprado realemente, e o sistema de "carrinho de compras" é apenas uma simulação visual.

---

## 📄 Descrição do Projeto

O **Susu - Art Market** é um site simples de página única (single-page) construído para apresentar uma coleção pessoal de arte digital e analógica (escaneada/desenhada à mão). O layout foi projetado para simular a experiência de navegação de um e-commerce de arte independente.

### 🖼️ Estrutura do Site (Baseado nas Prints)

Conforme as capturas de tela anexadas, o site está organizado em duas seções principais:

1.  **Cabeçalho e Seção "Sobre a loja":** Apresenta o nome do projeto "Susu - Art attack" (no logo) e um texto introdutório que convida o visitante a explorar a diversidade de estilos das criações exclusivas.
2.  **Seção "Produtos":** Uma grade interativa que exibe miniaturas dos desenhos com títulos, descrições breves e botões de simulação ("Adicionar ao carrinho").

## 🎨 Coleção de Arte (Hobby)**

O site apresenta diversos estilos de arte, incluindo:
*   **Desenhos Tradicionais à Lápis/Nanquim:** Ex: "Amor Natural", "Grito Interior".
*   **Fan Art de Anime/Mangá:** Ex: "Ichigo, de Bleach", "Kaneki" (de Tokyo Ghoul).
*   **Ilustrações Estilizadas:** Ex: "Explosão de fofura", "O Gato" (inspirado no País das Maravilhas).

## 🛠️ Stack Tecnológica (Dedução Baseada no Portfólio)

Como este é um projeto antigo focado em portfólio visual de hobby, ele geralmente utiliza uma stack web leve e moderna (verifique os arquivos do repositório para confirmação exata):
*   **Linguagem Principal:** TypeScript ou JavaScript (ES6+).
*   **Framework/Biblioteca (Provável):** React.js (comum para simulações de página única interativas).
*   **Implantação:** Vercel (conforme a URL de demonstração).

### 2. Executar Localmente (Se aplicável)
Se você clonar o repositório, os passos de instalação padrão geralmente são:
1. Instale as dependências: `npm install`
2. Inicie o servidor de desenvolvimento: `npm start` ou `npm run dev`
3. Abra `http://localhost:3000` (ou similar) no seu navegador.
